# Extensiones para Mesa Jack

Cada carpeta es una extensión independiente para Chrome o Edge. En la página de extensiones del navegador, activa **Modo de desarrollador**, elige **Cargar descomprimida** y selecciona la carpeta que contiene su manifest.json. Si descargaste un ZIP, extráelo primero.

Abre **Mi menú**, pulsa un desayuno y baja a **Preparación**. **Escuchar preparación** usa la voz disponible en el dispositivo y permite detener la lectura. **Imprimir receta** abre una tarjeta con las cantidades mostradas y el diálogo de impresión (también admite guardar como PDF). Puedes activar o desactivar cada extensión por separado. Recarga la ficha después del cambio.

Las dos extensiones se ejecutan en el navegador y reconocen las fichas del planificador. No requieren cuentas de terceros.
